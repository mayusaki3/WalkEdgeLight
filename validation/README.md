# Validation

This directory contains experimental implementations and validation assets for WalkEdgeLight.

The contents are for feasibility studies and PoC work and are not part of the formal product implementation.

Formal specifications and formal test specifications are not required for work under this directory during the validation phase.

## Initial validation

The first validation target is P0: synthetic geometry and perfect-depth based validation.

Planned progression:

- P0-A: sensor geometry validation
- P0-B: ground-plane estimation
- P0-C: height-discontinuity detection
- P0-D: edge geometry
- P0-E: parameter sweep

Implementation details and directory structure may change freely as validation progresses.
